# Victor Soto — Portfolio

Personal portfolio and resume site, generated by [Zola](https://www.getzola.org/), a fast static-site generator written in Rust. Zola builds plain HTML and CSS; the published site has no JavaScript runtime or external font dependency.

## Local development

Install Zola, then run:

```sh
zola serve
```

Build the production site into `public/`:

```sh
zola build
```

Resume content lives in [`content/_index.md`](content/_index.md); the page template and styles live in `templates/` and `static/`.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` builds with Zola and deploys to GitHub Pages on pushes to `master`. In repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
